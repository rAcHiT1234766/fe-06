# DashKit

DashKit is a library that puts analytics dashboards inside another company's product. The dashboards
take on that product's colours, fonts and logo, show each signed-in user only the data they are
allowed to see, filter each other when a chart is clicked, and can be rearranged by editors.

## Using this Storybook

Every story is live. It runs the SDK against the demo data API, which here answers inside the
browser through a service worker, using a snapshot of World Bank indicators for 2000 to 2024. Saved
changes last until the page reloads.

The toolbar applies to every story unless the story says otherwise:

| Control | What it changes                                                                                     |
| ------- | --------------------------------------------------------------------------------------------------- |
| Brand   | The theme: DashKit's default or one of the three demo customers' brands.                            |
| Mode    | Light, dark, following the system, or the brand's own choice.                                       |
| User    | Who is signed in. Each user gets their own embed token, and the API shows them only their own data. |

| User  | Customer     | Role   | Regions they may see            |
| ----- | ------------ | ------ | ------------------------------- |
| Asha  | Acme Global  | editor | all                             |
| Ravi  | AsiaInsights | viewer | South Asia, East Asia & Pacific |
| Elena | EuroStat Co  | editor | Europe & Central Asia           |

## Two ways to install

- **npm:** React apps install `@dashkit/sdk` and render its components. React is a peer dependency.
- **Script tag:** any web page loads `dashkit.js` and uses the `<dashkit-dashboard>` element. This
  build bundles its own React.

Both are built from the same source code.

## How the code is organised

| Layer   | Responsibility                                                       |
| ------- | -------------------------------------------------------------------- |
| Core    | Types, data requests, filter state and theme tokens. No React.       |
| React   | Dashboard, builder and widget components built on the core.          |
| Element | The `<dashkit-dashboard>` custom element that wraps the React layer. |

Dependencies point one way only: element → React → core.
